# 🎮 Game Glitch Investigator: The Impossible Guesser

## 🚨 The Situation

This starter project is an AI-generated Streamlit number-guessing game with
deliberate logic, state, scoring, and input-validation bugs.

## 🛠️ Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run the broken app: `python -m streamlit run app.py`

## 🕵️ Mission

1. Play the game and reproduce its glitches.
2. Connect visible symptoms to their code-level causes.
3. Refactor the game logic into `logic_utils.py`.
4. Repair the bugs and verify the behavior with pytest.
